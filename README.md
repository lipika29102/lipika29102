- **Performance:** cut the admin panel's heaviest pages from **~10.5 s to ~0.6 s** (request-level caching, stale-while-revalidate, fewer round trips).
- **AI astrologer:** measured latency over ~2,000 answers and moved short answers to **validated part-by-part streaming**, so the first text shows in seconds instead of ~22 s; added **photo input** (palm, face, Vastu floor plans) to the AI chat.
- **Payments:** Razorpay end to end — idempotent refunds, partial refunds for multi-item orders, webhook recovery, and fixes for double-charge / double-refund races.
- **Real-time:** Agora calls & livestreams, Pusher/WebSocket chat, a live waitlist with wallet-based wait times and per-user privacy.
- **Security:** closed authorization gaps in call tokens, host-only routes and auth deep links.
- **Quality:** every fix ships with tests — the backend runs **4,500+ automated tests**.
